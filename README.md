# CX318_Project_Software

---

## System

This project is a Wire and Hoop game, based on the NXP FDRM-MCXN947 microcontroller. It utilises the MAXREFDES117# board, which includes the MAX30102 sensor.

The main focus of the project was to raise awareness of non-communicable mental health issues related to stress, as per UN SDG 3, specifically Target 3.4. Included in the ```\docs``` folder is the user guide as required as a final deliverable for our project

## Game Description

The code was deployed onto the above NXP microcontroller, which was then connected to external peripherals including the heart rate sensor, the NXP OLED shield, a handle containing a metal hoop and motor, to mention a few.

This game was then begun by placing the grounded hoop against the 'Start' contact on the base, lifting off to begin the timer / measuring of heart rate, and utilised a state machine approach for the game logic.
